## 目标

| 角色 | 要能做到 |
|------|----------|
| 带卡点的访客 | 从「提问」入口提交后得非空 **nextStep**，线索入池；示例只填草稿，不自动消耗试用 |
| 来读的访客 | 从「文章」入口读公开笔记；可赞、可读后反馈（与赞分列） |
| 站主 | 闭环可转；管理端四面（概览 / 内容 / Agent / 运营记录）+ 底部设置，一人可养。内容可在界面内查阅与编辑。Agent 角色、部署与运行记录在对应主面管理。 |

成功 = 过程可转 + 使用价值可感知 + 安全诚实。
不成功 = 只像旧站皮肤，或后台很多但闭环转不起来。

## 原则（不可妥协）

1. **一个过程，两个接口**——禁止第二套业务真相。
2. **使用价值优先**——nextStep、有用/没用、yes/no 压过点赞。
3. **AI 可关**——关 AI 时 nextStep 仍非空；禁止 AI 自动主选/自动 yes。
4. **一人可养**——公开主任务 ≤2；管理默认 ≤4 面。
5. **安全 > 质量 > 效率**——安全未绿不得称可上线。
6. **Razor**——不增加线索/对准/可验结果的能力默认不做。

## 范围

**做：** 提问 intake、文章阅读、线索/题苗/执行/指标、鉴权写路径、反馈分列。

**不做 / 延后：** WorkItem 全家桶、Match 双轨、Skill 晋升全链、ObjectGrant、NorthStar 订单、账号全量、阅读遥测 50/90、以视觉保真为 KPI。

## 行为摘要

- **提问** `/tools`：**对话式**（写下卡点 → 原地返回回答，一问一答可继续；示例只填入草稿，访客明确发送后才提交）。回答含 nextStep 逐字呈现 + 结构化排版 + 依据折叠；最近一条可由 `/tools/result`（noindex）深链或刷新还原。依据只列服务端真实字段（AI/规则来源、规则桶语义、命中触发词、线索编号与池状态），**不展示模型内部推理**；结果只在本机浏览器会话可还原，链接分享不出内容（诚实空态）。配额/限流/无库须明确失败。
- **文章** `/posts`：公开内容**唯一总览**（统一时间流 + 标签筛选）；详情 `/posts/:slug`。旧 `/content` 重定向到文章，不设第二总览。
- **实验**：分为向外做事的**探索** `/explore`，和向内形成认识的**札记** `/lab`。探索内的点子 / 项目是明确的内容归属；状态只描述推进程度，不自动改变归属。
- **站主**：入池 → 主选 → 交付 → 检验（无线索不可主选）。

## 远景与中远期边界（原 VISION）

> **性质**：方向与边界，指导长远演进，不抢近端验收。本文防止意图被「只做双入口」或「只堆内容皮」冲掉。

### 核心远景：知识 → 工作站 → 回灌

- **人的认识沉淀为知识库；库上建工作站（Agent）；服务判断与行动（数字先，具身后）；行动数据回灌知识。**
- 社会面上做 **点子社区**：每人可有智能微体站（影子 + 行稳致远的助手）。
- **Walker** 是站名与**先跑通的样板节点**；**duola** 是人，知识主权在人。

### 三阶段闭环

| 步 | 含义 |
|----|------|
| **知识来源** | 来自人的总结与方法，不是爬来的公知堆。公开内容是库的可读切片；工作站要能**调用**这些认识，而不只是展览 |
| **决策支持** | 提供给智能做判断；**人定框架，智能在框架内执行**。具身智能为远期执行器，近端不做交付物 |
| **数据闭环** | 行动采集证据 → 写回库 → 认识随实践更新 |

### 点子社区与 NorthStar 边界

| 概念 | 是 | 不是 |
|------|----|------|
| **点子社区** | 点子相遇、共创、共促；微体站网络 | NorthStar 换皮 |
| **智能微体站** | 每人的影子（方法外化）+ 成长助手 | 仅博客皮肤 |
| **NorthStar** | **另一项目**；提供分发等能力 | 点子社区本体 |
| **关系** | 点子与内容的**分发与产品设计，参照 / 建在 NorthStar 能力之上** | 把社区中台做进 iwalk |

社区复杂度不灌进 Walker 单站；样板验证前不做多租户复制。

### 从远到近（时序与主航道）

```text
远   微体站网络 + 点子社区（分发依托 NorthStar 能力）
     具身行动用个人方法库决策并回灌

中   Walker 样板：库可被 Agent/规则引用进决策与 nextStep
     数字闭环：问题 → 引用知识 → 行动/交付 → 检验 → 改库

近   PRODUCT：公网提问可用 + 文章可读；一人可养的小生产四面（旧称「卡 / 逛」的生产双入口已于 2026-09-03 切流；本地新称呼未部署）
```

**近端唯一主航道**：把样板站做成「真有知识底座、真能辅助下一步与闭环」。社区复制与具身，等样板证明「影子有用」再开。公开页「关于本站 · 计划」与本文同向；冲突时以本规范为准。
