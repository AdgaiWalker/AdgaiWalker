## 目标

| 角色 | 要能做到 |
|------|----------|
| 带卡点的访客 | 10 秒分清「卡」；提交后得非空 **nextStep**，线索入池 |
| 来读的访客 | 「逛」读公开笔记；可赞、可读后反馈（与赞分列） |
| 站主 | 池 / 苗 / 检 / 数可转闭环；管理端三个工作面（计划 / 内容 / 复盘）+ 底部设置，一人可养。内容面拆文章台与项目台，可在界面内走完草稿 → 审核 → 上线，不必打开终端。Agent / 观测 / 结构在设置里。 |

成功 = 过程可转 + 使用价值可感知 + 安全诚实。  
不成功 = 只像旧站皮肤，或后台很多但闭环转不起来。

## 原则（不可妥协）

1. **一个过程，两个接口**——禁止第二套业务真相。  
2. **使用价值优先**——nextStep、有用/没用、yes/no 压过点赞。  
3. **AI 可关**——关 AI 时 nextStep 仍非空；禁止 AI 自动主选/自动 yes。  
4. **一人可养**——公开主任务 ≤2；管理默认 ≤4 面。  
5. **安全 > 质量 > 效率**——安全未绿不得称可上线。  
6. **Razor**——不增加线索/对准/可验结果的能力默认不做。

## 范围

**做：** 卡 intake、逛内容、线索/题苗/执行/指标、鉴权写路径、反馈分列。  

**不做 / 延后：** WorkItem 全家桶、Match 双轨、Skill 晋升全链、ObjectGrant、NorthStar 订单、账号全量、阅读遥测 50/90、以视觉保真为 KPI。

## 行为摘要

- **卡** `/tools`：**对话式**（写下卡点 → 原地返回回答，一问一答可继续；类型只作空态示例引导，不随提交发出）。回答含 nextStep 逐字呈现 + 结构化排版 + 依据折叠；最近一条可由 `/tools/result`（noindex）深链或刷新还原。依据只列服务端真实字段（AI/规则来源、规则桶语义、命中触发词、线索编号与池状态），**不展示模型内部推理**；结果只在本机浏览器会话可还原，链接分享不出内容（诚实空态）。配额/限流/无库须明确失败。  
- **逛** `/posts`：公开证据**唯一总览**（统一时间流 + 标签筛选）；详情 `/posts/:slug`。旧 `/content` 重定向到逛，不设第二总览。
- **实验**：分为向外做事的**探索** `/explore`，和向内形成认识的**札记** `/lab`。探索内的点子 / 项目是明确的内容归属；状态只描述推进程度，不自动改变归属。
- **站主**：入池 → 主选 → 交付 → 检验（无线索不可主选）。

## 词汇（SSOT）

| 词 | 含义 | 路径/键 |
|----|------|---------|
| 卡 | 带着问题来（对话式 + 结果页） | `dualEntry.ask` → `/tools` · 结果页 `/tools/result` |
| 逛 | 读证据（唯一公开内容总览） | `dualEntry.browse` → `/posts` |
| 实验 | 向外行动与向内认识的上位空间 | 探索 + 札记 |
| 探索 | 从念头到交付的同一件事 | `/explore` → 全部 / 点子 / 项目 |
| 札记 | 实验中沉淀的经验与思考 | `/lab` |
| （兼容） | 旧内容宇宙路径 | `/content` → 重定向到逛 |
| 线索 / 题苗 / 执行 | 生产过程对象 | admin 四面 |
| nextStep | 下次可执行一步 | intake 响应 |

禁止在页面硬编码 `'/tools'`、`'/posts'`——读 `dualEntry` / `WEB_ROUTES` / `ADMIN_ROUTES`。
