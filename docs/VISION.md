# 远景（半页）

> **性质**：方向与边界，**不是**近端验收。  
> **近端仍以** [`PRODUCT.md`](./PRODUCT.md) **为准**（卡 / 逛 + 线索→题苗→交付→检验；生产真可用）。  
> 本文防止意图被「只做双入口」或「只堆内容皮」冲掉。

---

## 一句话

**人的认识沉淀为知识库；库上建工作站（Agent）；服务判断与行动（数字先，具身后）；行动数据回灌知识。**  
社会面上做 **点子社区**：每人可有智能微体站（影子 + 行稳致远的助手）。  
**Walker** 是站名与**先跑通的样板节点**；**duola** 是人，知识主权在人。

---

## 个体：知识 → 工作站 → 回灌

| 步 | 含义 |
|----|------|
| 知识来源 | 来自人的总结与方法，不是爬来的公知堆 |
| 决策支持 | 提供给智能做判断；**人定框架，智能在框架内执行** |
| 数据闭环 | 行动采集证据 → 写回库 → 认识随实践更新 |

公开内容（资源 / 教程 / 点子 / 项目 / 札记等）是库的**可读切片**；工作站要能**调用**这些认识，而不只是展览。

具身智能：远期执行器；近端只约束「方法可执行、结果可回传」，**不做近端交付物**。

---

## 社会：点子社区与 NorthStar

| 概念 | 是 | 不是 |
|------|----|------|
| **点子社区** | 点子相遇、共创、共促；微体站网络 | NorthStar 换皮 |
| **智能微体站** | 每人的影子（方法外化）+ 成长助手 | 仅博客皮肤 |
| **NorthStar** | **另一项目**；提供分发等能力 | 点子社区本体 |
| **关系** | 点子与内容的**分发与产品设计，参照 / 建在 NorthStar 能力之上** | 把社区中台做进 iwalk |

社区复杂度不灌进 Walker 单站；样板验证前不做多租户复制。

---

## 从远到近（执行顺序）

```text
远   微体站网络 + 点子社区（分发依托 NorthStar 能力）
     具身行动用个人方法库决策并回灌

中   Walker 样板：库可被 Agent/规则引用进决策与 nextStep
     数字闭环：问题 → 引用知识 → 行动/交付 → 检验 → 改库

近   PRODUCT：公网卡真可用 + 逛证据；一人可养的小生产四面
今   内容壳与分类、人/站、计划文案；生产 API 未切
```

**近端唯一主航道**：把样板站做成「真有知识底座、真能辅助下一步与闭环」。  
社区复制与具身，等样板证明「影子有用」再开。
