# V13 目标和验收：公开成员切换与历史恢复

日期：2026-09-24  
状态：本地已验收，未部署  
进度唯一来源：根 [`to-do.md`](../../to-do.md)

## 目标

文章页从当前启用且通过发布门槛的部署 manifest 展示可选成员。访客只能选择该位置当前代次下的成员；切换成员保留同一业务 Conversation 时间线，并按 Agent 修订恢复各自的 SDK session。刷新页面后按匿名 cookie 和文章位置恢复业务 Message。成员或部署代次已变化时，拒绝旧选择并提示页面更新。

## 边界

- manifest 只暴露部署成员 opaque key、展示名称、修订序号和默认 key，不暴露 agent/revision 数据库 ID、prompt、模型配置或凭据。
- 历史路由由服务端 cookie 定位 Conversation；响应设置 `private, no-store`，不返回 anon hash、SDK session、attempt/run ID。
- 历史回答只在文章仍处于核验公开快照、对应修订仍属于当前合格公开部署时返回正文。已撤出的修订只返回隐藏占位；pending/unknown 不恢复。
- 工作范围仅 V13。访客停止、交互事件、保留与删除、内容写入和生产启用仍按后续任务处理。
