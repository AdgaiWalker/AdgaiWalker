### 4.2 反向：隔离守卫主动拒绝指向开发库

把 `API_TEST_DB_URL` 显式指向开发库后运行 vitest：

```
Startup Error
Error: API_TEST_DB_URL 必须是绝对路径的独立 SQLite .test.db 文件
```

**启动即失败**（fail-closed），不存在「配错就写开发库」的路径。机制上有三道：
1. `apps/api/vitest.config.ts` 强制改写 `DATABASE_URL`，且校验必须绝对路径 + `.test.db` 结尾，否则抛错；
2. `apps/api/vitest.global-setup.ts` 每轮删除并重建测试库（同样校验，非独立 `.test.db` 直接拒绝）；
3. 回归后测试库被重建（size 变化），开发库不动。
