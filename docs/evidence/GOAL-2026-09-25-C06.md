# C06：文章编辑、差异与预览

## 实施结果

- **纯函数文本行级差异工具**：在 `packages/shared/src/text-diff.ts` 中实现了基于最长公共子序列（LCS）的纯函数行级比对算法 `computeTextDiff`，输出新增（added）、删除（removed）、未改动（unchanged）行统计与行号映射，供人工编辑差异、冲突比对及后续候选审阅复用。在 `packages/shared/src/agent-ops.ts` 的 `OpsContentDetail` 中补充了 `hash: string` 强类型。
- **受控保存接口适配**：在 `apps/admin/src/api/queries.ts` 中增加了 `useSaveContent` mutation 与 `fetchContentDetail`，在前端保存时通过 `expectedHash` 携带基线版本 `baseHash` 请求受控接口 `PUT /admin/content/:slug`；成功后更新本地基线 hash 与状态，明确标注“工作区已保存（未发布上线）”，保持 A02 规则（保存与发布严格解耦）。
- **文章详情编辑与三态切换**：在 `apps/admin/src/pages/content/ContentDetailPage.tsx` 重构了编辑器面板，支持“编辑”、“预览”、“本地差异”、“原文与元数据”标签页切换，全面使用 `lucide-react` 图标（Pencil、Eye、GitCompare、FileText、Save、RotateCcw、CircleAlert），零 Emoji。
- **未保存保护**：
  - 刷新/关闭页面：通过 `window.addEventListener('beforeunload')` 拦截未保存改动的页面卸载。
  - 内部导航拦截：当存在未保存更改时拦截“返回内容列表”导航，弹出保护确认弹窗；用户可选择“留在本页”保留修改，或“放弃更改并离开”继续导航。
- **版本冲突保护（409 Conflict）**：
  - 当保存请求遇到 409（`content-version-conflict`）时，不自动覆盖用户本地修改，完整保留本地 draft 输入。
  - 自动拉取远程最新版本，展示显式冲突警告横幅与“冲突比对”标签，呈现远程修改与本地草稿的行级差异。
  - 提供站主自主决策出口：“以我的修改为准（更新基线后可重试保存）”或“放弃本地修改（使用远程版本）”。

## 验收边界

- 本任务接通的是工作区人工编辑、保存、差异比对与未发布状态展示，不等于文章发布上线。
- 文章发布依然严格等待后续的发布范围预检（C12）、工作区锁（C13）与受控发布链。
- 未引入任何兼容旧代码，UI 严格使用 Lucide 图标，无 Emoji。
