# V15 目标和验收：助手部件交互事件

日期：2026-09-25  
状态：本地已验收，未部署  
进度唯一来源：根 [`to-do.md`](../../to-do.md)

## 目标

记录文章页助手部件内的展示、介绍关闭、面板开合、提问、追问、成员切换、引用点击和回答反馈，为后续访客运营复盘提供可校验事件。事件只覆盖助手部件，不收集全站点击或任意 URL。

## 数据与信任边界

- shared 定义 `schemaVersion: 1`、事件枚举、字段白名单及事件专属校验；`url`、自由属性、未知事件/字段和超长/非法标识拒绝。
- `/assistant/events` 是同源公开 POST；服务端按匿名 cookie 和文章位置定位 Conversation，不接受客户端 conversationId。
- 有成员时，memberKey 必须属于当前位置当前公开 manifest；messageId 必须属于同访客/同文章的助手消息；引用目标还必须属于对应 assistant run 的已校验 citations。
- `eventId` 写入 FeatureEvent 唯一键，重复上报返回 duplicate 且不重复建行。客户端 `occurredAt` 只记为 `clientOccurredAt` 元数据；`receivedAt` 使用数据库服务端默认时间。
- 存储事件不含消息正文、原始 URL、IP 或匿名明文；存储失败不阻断问答/浏览流程。
- 不新增数据库迁移，复用 V07 ConversationRepository/FeatureEvent 表。

## 验收证据

- **RED**：shared 测试先因 `assistant-interaction` parser 缺失而无法加载；API 集成先观察 `POST /assistant/events` 返回 404。
- **GREEN / shared**：`pnpm test:shared`，41 个文件、327 项通过，新增 2 项事件合同测试覆盖合法事件与未知字段/URL/非法 ID 拒绝。
- **GREEN / API**：`pnpm test:api`，76 个文件、415 项通过。真实 AppModule/SQLite HTTP 测试覆盖同源限制、eventId 去重、消息与访客/Conversation 关联、规则答案不能伪造已引用文章，以及服务端 receive time 不受 client timestamp 影响。
- **GREEN / web**：`pnpm test:web`，39 个文件、226 项通过。测试覆盖助手部件事件包含 exposure、intro dismissal、open/close、member switch、accepted send/follow-up、citation click 与 feedback；事件只提交 message/member/slug 等白名单 ID。
- **GREEN / agent**：`pnpm test:agent`，5 个文件、30 项通过。
- `pnpm typecheck`、`pnpm build:api`、`pnpm build:web` 和 `pnpm verify:geo` 通过。web 构建仍提示有大于 500 kB 的既有 chunk。
- 未调用真实模型、未部署。
