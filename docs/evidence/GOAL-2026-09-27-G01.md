# G01：完成旧数据导入与兼容读演练

前置：R24、V24、C24、O10。落点：幂等迁移/导入脚本、旧报表适配。
验收：K6；升级两次行数稳定，旧业务链可读、新记录单一权威写入；不以新表空白为理由删除旧历史。

## 1. 实现

### 1.1 逻辑与装配分离（单一真相源）

- 新增 `apps/api/src/migration/legacy-data-migration.core.ts`：**零 Nest 装饰器**的纯迁移逻辑，
  供 CLI 与 Nest 服务共用同一份实现，杜绝"脚本一套、服务一套"的双份漂移。
- 新增 `LegacyDataMigrationService`：薄壳，仅做 DI 装配后委托 core。
- 新增 `scripts/migrate-legacy-data.ts` + `pnpm legacy:migrate` 入口。

**为什么这样分层**：`scripts/tsconfig.json` 未启用 `experimentalDecorators`，
脚本一旦 import 带装饰器的 Nest 类即报 *Parameter decorators only work when experimental decorators are enabled*。
把纯逻辑抽成无装饰器模块，既复用同一份实现，又不必给脚本加装饰器配置。

### 1.2 溯源与去重（schema 增量）

`ExecutionRun` 增加 `legacySource` / `legacyId` 两列 + 唯一索引 `(legacySource, legacyId)`，
迁移 `20260927110000_execution_run_legacy_source`。旧 run 迁移后重复执行不会产生第二条。

### 1.3 四条迁移纪律

| 纪律 | 落实方式 |
|---|---|
| **幂等** | 每条旧记录先按 `(legacySource, legacyId)` 查存，已存在即跳过；第二次运行增量恒为 0 |
| **溯源去重** | 三类旧 run 分别以 `AgentRun` / `SkillRun` / `AssistantRun` 为 legacySource 落库 |
| **诚实未知** | `agentRevisionId` 一律为 `null`（无法恢复的修订不伪造）；用量为 0 时 `tokensIn/tokensOut` 记 `null` 而非 0 |
| **历史保全** | 旧表 `AgentRun` / `SkillRun` / `AssistantRun` **只读保留**，绝不删除 |

历史 `AgentUnit` 若无修订则生成初始修订（`version: 1`，`id: legacy-<agentId>`）并写审计；
`AssistantRun` 迁移时回写 `traceId` 并补齐 `ConversationLogResource` 会话索引（会话历史可查）。

## 2. 验证

### 2.1 K6 内核集成测试（`legacy-data-migration.kernel.integration.test.ts`，4 项全绿）

1. **首次迁移**：为历史 Agent 生成初始修订（version 1、提示词一致）；AgentRun 全量迁移且
   `state` 映射正确、`agentRevisionId` 为 `null`、有用量者保留 120/60、**无用量者为 `null` 而非 0**；
   SkillRun 迁移；AssistantRun 回写 `traceId` 并补齐会话资源索引。
2. **升级两次行数稳定**：第二次执行 `revisionsCreated / agentRunsMigrated / skillRunsMigrated /
   assistantRunsMigrated / conversationResourcesIndexed` **全部严格为 0**，
   修订数、执行运行数、会话索引数**三项行数逐一对齐不变**。
3. **旧业务链可读**：旧表 2 条 AgentRun 一行未删；旧报表适配器 `runs()` 返回 `total=2`、
   `agentName` 正确，`run(id)` 明细的 `instruction`/`output` 完整。
4. **新记录单一权威写入**：新增执行只写 `ExecutionRun`，旧表 `agentRun`/`skillRun` 行数**不增**（不双写）。

### 2.2 CLI 实测（隔离库两次执行）

在隔离库部署全部迁移、播种历史数据后连续执行两次：

```
第一次：revisionsCreated=1, agentRunsMigrated=1, skillRunsMigrated=1
第二次：revisionsCreated=0, agentRunsMigrated=0, skillRunsMigrated=0
```

第二次全部增量归零，与内核测试结论一致。
