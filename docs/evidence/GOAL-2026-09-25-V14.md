# V14 目标和验收：访客真实停止入口

日期：2026-09-25  
状态：本地已验收，未部署  
进度唯一来源：根 [`to-do.md`](../../to-do.md)

## 目标

访客在文章助手中主动停止当前模型回答。请求只提交当前助手 Message ID；服务端按匿名 cookie、文章位置、Conversation、Attempt 和服务端 run 关联校验归属，再调用统一执行生命周期。RUNNING 任务只有在 Runtime close 返回退出证明后才标记 CANCELLED；无法证明终止时保持 UNKNOWN，不显示为已停止。浏览器断开 SSE 只影响交付观察，不会取消模型运行。

## 实现边界

- 新增同源 `POST /assistant/conversations/:placementKey/:scopeSlug/stop`，请求体只有 `{ messageId }`；服务端不接受 `runId`。
- 公开执行停止再次校验 `origin=public`、匿名 actor 与 actorScope、文章位置与资源范围、chat kind、deployment 及无后台 grant。
- QUEUED 可直接转 CANCELLED；RUNNING 经 STOPPING 和退出证明后结束；UNKNOWN 表示停止未获确认。
- 客户端在 Message ID 可用后开放按钮；轮询 PENDING。只有 API 返回确认 CANCELLED 才标记停止并收起活动流；UNKNOWN/超时不会伪装成功。
- 确认取消后的 partial 保留在同访客历史里，刷新后显示为未完成且已停止。
- 部署启用、真实模型调用和生产变更不属于 V14。

## 验收证据

- **RED**：先加真实 AppModule HTTP 集成测试，停止路由未实现时同访客请求返回 404。
- **GREEN / API**：`pnpm test:api`，76 个文件、414 项通过。AppModule HTTP 测试覆盖同访客可停止、跨访客 404、跨站 Origin 403、伪造到后台 run 的 Message 不能停止后台 run；服务测试覆盖仅通过本访客 Conversation/Attempt 查找 run。Controller 测试断开 SSE 后确认执行服务没有收到 AbortSignal，并最终将交付标为 unknown。
- **GREEN / scheduler**：`execution-scheduler.kernel.integration.test.ts` 通过 `stopPublicRun` 测试队列立即取消、运行状态保持 STOPPING 直到 close 退出证明、退出后 CANCELLED，且迟到 `recordResult` 不能覆盖终态。
- **GREEN / web**：`pnpm test:web`，39 个文件、223 项通过。测试覆盖停止 API 请求体只有 messageId、pending 轮询、服务确认后才显示“已停止”，以及刷新后恢复停止前片段。
- `pnpm test:shared` 40 个文件、325 项通过；`pnpm test:agent` 5 个文件、30 项通过；`pnpm typecheck`、`pnpm build:api`、`pnpm build:web` 和 `pnpm verify:geo` 通过。
- web 构建有既有大 chunk 提示；本任务没有调整 bundle 拆分。
- 未调用真实模型，未部署。
