# 小影 · 影鳐 V2

本轮采用用户选择的 **B「影鳐」**：低矮、连续的影子身体，两侧柔软翼缘，小光眼，短钝的后缘。日常古灵精怪，协作时温柔勇敢。人定义价值与问题，小影提供选项、接手重复流程、连接不同表达。

这一方向取代此前猫形设计。新场景为 `Xiaoying_Yingyao_V2`；旧场景仅作为迭代记录保留，不是当前造型。

## 模型结构

主体 `YY_Continuous_Body` 是一张闭合、连续的双面曲面：10,114 个基础顶点、10,240 个基础面，并保留可调的细分修改器。中央体积、左右翼缘与短后缘共享同一张网格，避免拼接处开裂。

基础轮廓宽约 4.16 个 Blender 单位，中部最高约 1.15 个单位。角色正面朝向 -Y；角色右翼位于 -X，静止时略高翘。场景单位比例为 0.1，可整体等比缩放。

材质分为墨灰主体、较浅的柔软底面、暖色微发光眼睛、微小深色瞳孔和克制的笑线。眼睛贴合主体前部曲面，并随主体形变；保留正面、左右侧面、背面、俯视及主展示相机。参考图已打包进 `.blend`。

## 绑定与表情

`YY_RIG` 包含 7 根骨骼：Root、Body、左右内翼、左右外翼和 Wake。身体位置、倾斜及翼缘运动可继续编辑。

同一控制器上的浮点属性驱动主体和表情曲面：

| 控制 | 用途 |
| --- | --- |
| Cradle | 翼缘向内卷起，形成承接姿态 |
| Spread | 横向舒展，表现提供空间与选项 |
| PeekR / PeekL | 单侧翼缘上翘，表达好奇或两侧传递 |
| Breathe | 中央身体微幅呼吸 |
| Blink | 眼睛与瞳孔同步闭合 |

属性通常取 0–1。时间轴播放时，这些属性由动作驱动；手工摆姿态前可暂时静音对应 NLA 轨道。表情和形变属于 Blender 内的角色表现，尚未接入任何桌宠软件状态机。

## 七种状态

24 fps，展示时间轴共 1–696 帧，约 29 秒。每种状态拥有独立 Action、NLA 轨道和中文时间轴标记。

| 状态 | 帧范围 | 行为 |
| --- | --- | --- |
| 待机 | 1–96 | 微呼吸、翼缘慢摆、眨眼 |
| 好奇 | 97–192 | 一侧翼缘翘起，轻轻侧倾探看 |
| 倾听 | 193–288 | 前倾、慢点头，收住动作 |
| 展开选项 | 289–408 | 舒展翼缘后保持开放，等待人选择 |
| 执行 | 409–504 | 卷起两翼，交替做整理动作 |
| 转译 | 505–624 | 由一侧到另一侧的连续波动 |
| 完成反馈 | 625–696 | 一次轻弹、舒展，然后恢复安静 |

动作边界回到相同的中性状态。待机、好奇、倾听、执行标记为可循环；其余设计为一次性表达。动作是角色行为示意，不表示真实任务已被执行或完成。

## 验证范围

主体基础网格检查没有开放边或非流形边。检查了七组动作的边界控制值，以及中间帧的骨骼、形变和眨眼驱动；具体采样值见 `validation.json`。眨眼峰值能够到达 1，动作首尾控制值在浮点误差范围内一致。

这些检查覆盖当前 Blender 资产的结构与动作。实时引擎导出、目标设备性能、自动状态切换和完整逐帧碰撞测试尚未进行；模型不是已集成的桌宠应用。

## 可复现源文件

`build_yingyao.py` 创建场景、连续曲面、材质及绑定；`animate_yingyao.py` 创建动作；`finish_yingyao.py` 调整眼形和材质并检查、渲染；`fix_shape_controls.py` 从基础形态显式重建各形变目标，并重新检查。脚本通过 Blender MCP 在打开的 Blender 内执行。

当前 `.blend` 是直接使用的完整交付；重新运行构建脚本会创建新场景，不应在同一文件中反复运行。
