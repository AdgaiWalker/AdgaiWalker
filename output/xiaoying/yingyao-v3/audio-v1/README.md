# 小影 · 第一轮声音试样

先验证招呼、承接、开心三个状态。以同一组带气息的非语言双音节为声音签名：招呼上扬，承接下落，开心加快。身体声由柔软的滤波噪声与低频弹性起音构成；承接眼光峰值有极轻的暖音。

本轮全部声音为原创程序合成，不使用真人录音、声音克隆或外部采样。它是供试听与调整的音色方向，不代表最终角色配音。

## 试听

- `sound-preview.mp4`：招呼 → 承接 → 开心，约 11 秒，带声音的动作连播。
- `hello.mp4`、`receive.mp4`、`joy.mp4`：三个独立声画片段。
- `hello.wav`、`receive.wav`、`joy.wav`：48 kHz、16 bit、立体声 PCM，分别为 3、5、3 秒，包含与动作匹配的空白。
- `sound-preview.wav`：三段纯音频连播。
- `full-motion-with-sound.mp4`：约 36.5 秒的原完整动作预览，仅上述三个状态有本轮音效。
- `stems/`：每个状态拆开的 voice、body、light 三层，所有文件保留相同长度，可从同一起点叠加。未使用的 light 层为静音。

图集 `../gallery.html?sound=1#sound` 提供声画连播、独立音频和下载。默认音量 65%，手动播放；同时只播放一个媒体。

## 时间与触点

Blender 原动作 30 fps，状态音频起点分别为第 136、376、811 帧。相对时间公式为 `(当前帧 − 状态起始帧) / 30`。

| 状态 | 主要声音事件 | Blender 全局帧 | 片段内秒 |
|---|---|---|---|
| 招呼 | 抬翼摩擦 | 150 | 0.467 |
| 招呼 | 双音节上扬回应 | 160 / 170 | 0.800 / 1.133 |
| 招呼 | 第二次挥翼摩擦 | 184 | 1.600 |
| 承接 | 展开浅盘 | 392 | 0.533 |
| 承接 | 道具显现时的轻承托 | 439 | 2.100 |
| 承接 | 双音节下落确认 | 445 / 455 | 2.300 / 2.633 |
| 开心 | 压身蓄力 | 818 | 0.233 |
| 开心 | 双音节轻快回应 | 832 / 839 | 0.700 / 0.933 |
| 开心 | 主落地 | 862 | 1.700 |
| 开心 | 第二次轻弹摩擦 | 869 | 1.933 |

完整事件表见 `cue-sheet.json`。承接道具在原动画中逐渐缩放显现，没有向下落地；配的是轻承托声。开心的主落地第 862 帧有明确软着陆声，最终归位只保留微弱布料声。

视频复用原 15 fps 预览，独立片段以 30 fps 封装（重复帧），视觉精度仍为原 15 fps；音效以 48 kHz 按原 30 fps 动作时间码定位。最接近的画面帧可能相差约 33 毫秒。

## Blender 试音工程

`xiaoying-sound-study.blend` 是单独保存的试音工作文件。原 `../xiaoying-yingyao-v3.blend` 和无声视频保留。

- 场景中的 Sequencer 有三条原生 Sound Strip，对齐第 136、376、811 帧。
- 三段 WAV 已打包进工程，文件移动后仍可播放。
- 默认停在招呼开始的第 136 帧，按空格播放时间线。
- 在 Video Sequencer 选择声音条带可调整音量、静音与起点。默认各条带音量为 0.65，与图集初始音量一致。
- 原角色几何、材质和八个动作未修改。本轮只在三个状态配置音效，其他状态保持安静。

## 重建与检查

`create_sound_study.py` 使用 NumPy、SciPy、imageio-ffmpeg，随机种子固定。运行后生成 WAV、分层、带声音的视频和 `cue-sheet.json`。所有声音采用共同增益，保留承接较轻、开心稍亮的动态差异。

`validation-audio.json` 记录采样率、时长、峰值、4 倍过采样峰值、直流偏移与削波样本数。`validation-media.json` 记录媒体解码检查；`validation-blender.json` 记录音频打包与时间线条带检查。
