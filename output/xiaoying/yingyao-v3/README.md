# 小影 · 影鳐 V3.1 · 质感对齐版

参考用户提供的影鳐概念图，在 Blender 5.2 中通过 MCP 建模、绑定和制作动作。本轮围绕柔软体积、深色顺毛绒面、内嵌眼窝和真实接触阴影调整质感；保留原有角色比例、8 个独立动作、13 个控制参数与 30 fps 动画。

## 本轮质感更新

- 连续翼截面厚化，并让厚度随抬翼弯曲旋转；下腹增加柔软接触面，强化身体落在台面上的重量感。
- 深色顺毛材质使用 `XY_Rest` 稳定坐标，避免形态变化时纹理漂移；暖灰腹面延续细绒质感。
- 新增 75,621 条贴伏微绒，长度约 0.9–2.25 mm、高度约 0.04–0.12 mm。旧直立短绒保留并默认隐藏。
- 眼窝加深，面部重新投射到细分曲面；瞳孔去除清漆反射，暖光随眨眼同步变化。
- 奶油背景使用地面专用柔光，保留真实接触阴影，统一全部状态的拍摄质感。

图集可在“原版 / 质感对齐”之间切换主视觉，查看本轮调整。

## 声音试样 01（2026-09-10）

第一轮声音研究包含招呼、承接、开心三个状态，使用原创程序合成音色，不含真人配音。三段共享轻柔回应与细绒摩擦的声音质感，并按现有动作的抬翼、收拢与落地节奏安排声音。

- 图集的“听见小影”区域提供 11 秒声画连播及三个独立音频控件；点击播放才会出声，初始音量为 65%，页面内音频与视频互斥播放。
- `audio-v1/hello.wav`、`receive.wav`、`joy.wav`：三段音效，分别为 3、5、3 秒；同名 `.mp4` 是对应的带音效动作片段。
- `audio-v1/sound-preview.mp4` 与 `sound-preview.wav`：按招呼 → 承接 → 开心顺序连播，时长 11 秒。
- `audio-v1/xiaoying-sound-study.blend`：单独的试音工程，包含三段原生声音 strip；角色视觉工程与原始无声版视频保留。
- `audio-v1/README.md`：音色与同步说明；`audio-v1/cue-sheet.json`：声音时点记录。

本轮用于试听和确定声音方向，尚未接入网页产品的交互事件，其余五个状态也尚未制作音效。

## 打开与播放

- `xiaoying-yingyao-v3.blend`：完整工作文件，默认打开新建的 `XY3 • 小影 / 影鳐工作室`，停在第 167 帧招呼姿态。此前的场景保留。
- `xiaoying-asset.blend`：仅包含本次小影场景、相关资源、8 个动作和内嵌说明的独立资产。
- 按空格播放时间线；30 fps，1–1095 帧。8 段动作间留有 15 帧间隔，NLA 设有 10 帧淡入淡出。
- 时间线标记绑定原生相机切换：承接使用较高机位，表达使用广角构图，其余状态使用主机位。
- `states.json` 是动作区间的机器可读表。时间线标记和 NLA strip 使用相同名称。
- 独立动作已标记为 Action Asset，可以在 Action Editor / Asset Browser 中复用。循环标记写入各 Action 的 `loop` 自定义属性。

## 动作行为

| 状态 | 建议触发 | 实际动作 | 帧段 | 时长 | 类型 |
|---|---|---|---|---|---|
| 待机 | 没有新输入 | 背部慢呼吸、双翼轻微错相浮动、自然眨眼 | 1–120 | 4 秒 | 循环 |
| 招呼 | 初次出现、主动打招呼 | 轻压身体蓄势，左翼卷起后挥动两次，再放下 | 136–225 | 3 秒 | 单次 |
| 倾听 | 用户正在输入或说话 | 翼缘稍抬、身体轻倾、视线偏向输入方向 | 241–360 | 4 秒 | 循环 |
| 承接 | 收到用户交付的内容 | 背部凹成浅盘、两翼与后缘环抱，随后呈现三件示意道具 | 376–525 | 5 秒 | 单次 |
| 思考 | 正在处理信息 | 视线左右回望、后缘缓摆、翼缘小幅交替抬起 | 541–660 | 4 秒 | 循环 |
| 表达 | 开始输出清晰答复 | 双翼展开，暖金线连接左侧思绪与右侧圆环 | 676–795 | 4 秒 | 单次 |
| 开心 | 用户认可或一件事完成 | 轻压蓄势、短距离弹起、双翼同时抬升、柔和回落 | 811–900 | 3 秒 | 单次 |
| 休息 | 长时间无交互 | 身体放低铺展、完整闭眼、眼光熄灭、保留慢呼吸 | 916–1095 | 6 秒 | 循环 |

以上“触发”是交互产品的行为设计建议。本资产实现了动画与控制参数，尚未接入网站事件。

## 比例与材质规范

- 场景单位：Metric，`scale_length = 0.05`；1 Blender 单位对应 50 mm。
- 中性翼展 320 mm，身体前后长度约 150 mm，中性高度约 69 mm。动作造成的压缩、弯曲与伸展为有意设计。
- 身体与双翼共用一张封闭曲面；基网格 8,066 顶点、8,192 面，主体为四边面，极点处三角扇；保留两级可编辑 Subdivision。
- 身体具有 UV、`XY_Belly` 腹面混合属性与 `XY_Rest` 静止坐标，程序材质无需外部纹理。
- 炭灰微绒使用低镜面反射、柔和绒光和顺毛纹理；腹面为带细绒的暖灰米色。微绒的长度与高度按上述场景单位换算。
- 贴伏微绒用于近景细节；旧对象 `XY3_FUR • 短绒细节` 默认隐藏，作为原始版本保留。
- 杏仁眼有贴合细分曲面的深眼窝、暖金眼光与可移动瞳孔；闭眼时瞳孔收进眼睑下，眼光与局部暖光同步熄灭。
- 微笑为贴合身体曲面的细小暗槽与柔光唇缘。
- 道具采用同一暖中性色系和柔和倒角；连接线只在表达状态出现。
- 棚拍包含无缝奶油地面、大面积柔光、地面专用柔光与六个机位。

## 手工调整

选择 `XY3_CTRL • 小影总控`，进入 Object Properties → Custom Properties：

`Breath`、`Wing_L`、`Wing_R`、`Receive`、`Rest`、`Tail_Sway`、`Squash` 控制软体形态；`Blink_L`、`Blink_R`、`Gaze_X`、`Glow` 控制表情；`Cargo` 与 `Signal` 控制演示元素。

绑定使用形态键与总控驱动，不依赖外部脚本、逐帧 handler 或骨骼插件。手动调参前，在 NLA Editor 暂时静音 `XY3 / 8 个状态 · 顺序预览` 轨道，避免时间线覆盖参数。恢复轨道即可继续播放演示。

`Receive`、`Rest`、`Squash` 主要用于各自状态，不建议把三个极值同时叠满；正式产品状态切换建议沿当前姿态插值 0.2–0.35 秒。供动画师继续修订的单一控制结构已建立。
